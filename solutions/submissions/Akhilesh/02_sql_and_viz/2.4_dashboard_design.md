## 3. Visual Components Specification

### Visual 1 — KPI Summary Cards (Executive Overview)
- **Visual Type:** 5 High-Impact Metric Cards
- **Metrics & Business Rationale:**
  1. **Total Budget:** `154,820,000 AED` (Denominator of fiscal allocation)
  2. **Total Actual Spend:** `142,390,000 AED` (Total capital disbursed across all active & closed projects)
  3. **Net Budget Variance:** `-12,430,000 AED` (Overall favorable by 8.0%, though masked by project-level overruns)
  4. **% Over-Budget Projects:** `38.4%` (192 of 500 projects exceeded allocated budget; triggers executive audit)
  5. **Total Transactions:** `50,000` (100% completeness; total volume of audited financial line items)

### Visual 2 — Actual Spend vs. Budget by Department
- **Visual Type:** Clustered Horizontal Bar Chart
- **Data Source:** Analytical Query Q1 (`dim_project`)
- **Dimensions:** `department` (Y-Axis), `total_budget` (Bar 1), `total_actual_cost` (Bar 2)
- **Formatting:** Conditional color formatting: Red bar if `spend_percentage > 90%` or `over_budget = TRUE`.
- **Insight:** Highlights departments with severe burn rates requiring budget re-baselining.

### Visual 3 — Monthly Spend Trend by Category with Running Total
- **Visual Type:** Line Chart with Secondary Running Total
- **Data Source:** Analytical Query Q5 (`fact_transactions` joined to `dim_date`)
- **Dimensions:** `year_month` (X-Axis), `monthly_spend` (Y-Axis), `category` (Legend / Series)
- **Tooltip:** `running_total` and `month_over_month_pct_change`.
- **Insight:** Detects seasonal spending surges (e.g. Q4 cloud infrastructure true-ups) and category burn trajectories.

### Visual 4 — Vendor Concentration Risk
- **Visual Type:** Donut Chart (Top 5 Vendors + "Other" bucket)
- **Data Source:** Analytical Query Q3 (`dim_vendor` and `fact_transactions`)
- **Thresholds:**
  - `HIGH RISK (> 10%)`: Global Cloud Solutions (11.2%)
  - `MEDIUM RISK (5–10%)`: Emirates Tech Systems (8.4%), Gulf Network Security (7.1%), Abu Dhabi Cloud (6.3%), Apex Consult (5.2%)
  - `NORMAL (< 5%)`: Remaining 39 vendors aggregated into "Other" (61.8%)
- **Insight:** Procurement dependency alert: Top 5 vendors absorb > 38% of total enterprise spend.

### Visual 5 — Top 10 Projects by Budget Variance
- **Visual Type:** Data Grid / Table with In-Cell Data Bars
- **Data Source:** `projects_clean.csv`
- **Columns:** `project_id`, `project_name`, `department`, `status`, `budget`, `actual_cost`, `budget_variance`, `risk_level`
- **Sorting:** `budget_variance` DESC (largest over-budget first).

### Visual 6 — Interactive Global Slicers
- **Slicers:**
  1. `Region` (Abu Dhabi, Dubai, Sharjah, Northern Emirates)
  2. `Project Status` (Active, Closed, Pending)
  3. `Transaction Year` (2024, 2025)

## 4. DAX Measures for Power BI Implementation

```dax
// 1. Total Allocated Budget
Total Budget = SUM('dim_project'[budget])

// 2. Total Actual Spend
Total Actual Spend = SUM('dim_project'[actual_cost])

// 3. Net Budget Variance
Budget Variance = [Total Actual Spend] - [Total Budget]

// 4. Over-Budget Project Count
Over Budget Projects Count = 
CALCULATE(
    COUNTROWS('dim_project'),
    'dim_project'[is_over_budget] = TRUE()
)

// 5. % Over-Budget Projects
Pct Over Budget Projects = 
DIVIDE([Over Budget Projects Count], COUNTROWS('dim_project'), 0) * 100

// 6. Running Total Monthly Spend
Running Total Spend = 
CALCULATE(
    SUM('fact_transactions'[amount_aed]),
    FILTER(
        ALLSELECTED('dim_date'),
        'dim_date'[full_date] <= MAX('dim_date'[full_date])
    )
)
```
